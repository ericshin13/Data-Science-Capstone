# Data-Science-Capstone

This project involved a real-world client engagement where our data science team analyzed survey data to support the client’s analytical objectives. Because the dataset was messy and unstructured, we first cleaned, standardized, and validated the data in R, addressing missing values, duplicate information, inconsistent formatting, and open-ended responses. We then conducted exploratory data analysis and regression modeling to evaluate relationships between variables and identify meaningful insights.

Throughout the project, our team met with the client on a bi-weekly basis to present findings, discuss progress, clarify priorities, and incorporate feedback into our analysis. As the client’s priorities evolved, we adjusted the project scope and analytical approach to focus on the questions and variables that were most operationally relevant. This experience highlighted the importance of data validation, stakeholder communication, and flexibility when working on real-world analytics projects.
